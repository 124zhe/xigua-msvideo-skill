# 油管 MS Paint 分镜与生图

将已确认的口播与时间戳转换成可剪辑的独立横屏图片。默认中文沟通、英文视频使用简短英文画内标签。当前用户指令优先于本技能的既有偏好。

## 先判断当前阶段

- **只要时间戳或分镜**：交付对应文件，不提前生成图片。
- **学习参考或重设计**：实际查看参考画面，先改构图、动作和配色主次。
- **先生成几张看看**：选有代表性的少量镜头出样图，停在用户要求的范围。
- **认可样图后生成全部**：继承已认可标准，直接覆盖全部时间戳；复用符合当前分镜的已通过样图，不重复请求确认。
- **修改规则或整理技能**：完成这项工作，暂停尚未完成的批量生图；不把整理技能理解为自动恢复生图。

原稿、时间戳、画面设计与实际图片是四种不同产物。以磁盘上的最新认可版本为准；图片制作不改动口播。不把旧版输出当作新版完成量。

## 制作流程

### 1. 找齐脚本与参考

读取完整脚本、时间戳和既有分镜/样图，先列出准确帧数。文本只有脚本占位符时，不推测缺失旁白；先找当前项目文件，确实缺少再请用户补充。

开始新视觉方向或复核参考时，读 [画面语言](references/visual-language.md)。用户提供视频参考，查看多个时段的实际画面，覆盖场景、反应、机制与比较等类型。记录取样位置及观察范围；标题、字幕和缩略图不等于看过画面，取样不等于完整观看。已有可核对的参考分析与认可样图可复用。

### 2. 把时间和画面分开设计

- 已确认的时间戳逐一保留：**一个画面时间点对应一张独立图片**。一张拼图不算多个输出。
- 默认节奏是**约两秒一次明显的视觉变化**，用户另有要求时调整。这是设计目标，不是硬性每 2.000 秒切换，也不是参考视频的实测平均值。
- 不再机械执行“一句话一个镜头”：一句长旁白可以有多个视觉节拍，短短一个词不必单独切镜头。
- 已有认可时间戳时，除非用户要求重新切分，保持时间不变，靠景别、动作、注意中心、尺度或解释关系完成变化。
- 没有音频时按实际旁白估时并标明 estimated；有音频后再对齐。不可把估算写成精确配音时码。
- 切换画面不靠轻微缩放、挪位置、换字或只添一个问号充数。

### 3. 先设计每一帧

先确定当前语句的主体、发生的变化与画面关系，再安排人物、物件和环境。风景、自然现象、动物、器官、微生物、物件或机制均可独立成为主体；选择须符合题材与旁白，不为丰富度添加不属于该场景的对象。

人物可主可辅：既能承担动作与反应，也能在环境中作为观察者、尺度参照、互动者或笑点。旁白没有提到人时仍可有人，不把“不必每镜都有火柴人”变成“未提及人就禁止人物”。出场频率与占画面大小保持适当，服从信息重点和整段节奏，不设全片人物比例或数量配额。

每帧至少交代：

- 编号、开始/结束时间、对应原文；
- 画面主体、镜头类型、具体动作/状态、道具和环境关系；有角色时交代角色作用、位置与大小；
- 主要色块、次要色块、注意中心；
- 相对上一帧的大变化；
- 允许出现的短文字，以及相关事实/连续性约束。

设计后连看相邻 3–5 镜，检查主要形状、构图、动作、视点、尺度和信息结果是否有实质变化。人物参与、环境全景、物件特写、机制图和比较图按段落灵活组合，不机械轮流，也不靠增删一个人掩盖原本重复的构图。连续使用同一对象时要有动作或结果推进；连续海景、气体卡片、器官图同样需要检查。

画面丰富度来自行为和关系，不用无关物件填空，也不把每张都压缩成悬空的小图标。具体判断与连镜例子见 [人物主次与相邻镜头](references/visual-language.md#人物主次与相邻镜头)。

确立本片人物、设备、场地、概念颜色和状态变化的规则。每个独立提示词带上涉及的设定，不能只写“同上一张”。具体字段和提示词结构见 [生成与交付](references/production.md)。

### 4. 用代表性样图校准

新方向可选少量差异明显的样图，覆盖本片实际需要的环境/物件主体、人物主辅关系、机制或动作场景；数量随请求调整，不设固定配额。仓库附带四张古地球题材的 [风格示例](references/ancient-earth-example.md)，供理解画法，不代表当前用户已认可其角色与设计。

判断与修正要具体：主体是否太小、道具是否参与动作、颜色是否互相抢眼、相邻镜头是否重复。用户说“饱和度低”时，不只把全部物件同时涂亮；重新分配色块面积和主次。用户已认可样图并要求批量时，直接进入下一步。

### 5. 批量生成并保存

实际生图遵循当前可用生成工具及可用 imagegen 技能规则；在支持的环境中默认使用内置图像生成，每帧独立调用。仓库本身不提供生图服务；没有生成能力时先交分镜和提示词，并说明尚未生成。不要因“批量”自行切换 API/CLI，也不把用户粘贴的供应商示例当成指定渠道。

参考图必须标明是**风格/角色参考**还是**编辑目标**。使用认可样图保持线条、人物与配色，但新帧必须执行自己的构图和动作，不能复制参考的场景。支持本地参考时先查看图片，再传入实际路径。

按编号记录输出、提示词、参考图、实际尺寸与检查状态。每张成功后及时保存到当前项目；长批次定期说明实际完成数量、范围与下一段内容。用户打断后，不假设调用全失败或全成功：核对记录和文件，续作仅补缺失或未通过项。任务被明确叫停时不继续派发新调用。

### 6. 命名、核对、交付

默认命名：**三位分镜编号 + 开始时间戳**。具体格式、例子和时间精度见 [生成与交付](references/production.md#命名与时间依据)。

默认形如 `frame-007_00m11s839ms.png`。编号与时间来自同一版分镜，不用生成完成顺序命名。改时间或改版时保存明确的新版本，避免静默混用。

`scripts/frame_manifest.py` 可从分镜 JSON 生成命名计划，并核对缺帧、额外文件、文件头、真实尺寸及比例；它**不生成或编辑图片，也不代替视觉检查**。

交付整套独立图片、时间戳/旁白对照表、提示词、完成清单及可浏览的联系页。用户只要样图时按范围简化。已有图像是近似 16:9 就如实记录，不能因提示词写了 16:9 而声称文件严格符合比例。

最终检查帧数和时间戳覆盖、白底粗绘风格、鲜艳颜色主次、角色状态连续、文字拼写、重要对象不误裁、肢体和连接正确、科学条件没有被图像篡改。把相邻图片组成联系页，检查人物主次和连镜差异；分镜文字不同或脚本校验通过不等于实际画面已经有变化。所有预期图片均保存且检查通过，才称“全部完成”。

## 固定画面要求

- 横向 16:9、白底、粗细不均的黑线、歪斜手绘感、基础几何形、纯色平涂。
- 画面需要人类角色时使用圆头火柴人、点眼或简单圆眼、线身体和四肢、少量可读表情与手势。其他主体沿用相同粗绘语言；火柴人是人物的画法，不是每镜必有的元素。
- 鲜艳颜色有主次；海面、地面、桌面等可形成局部大色块，白底不等于固定留白比例。
- 画得业余、简单、有趣；构图仍清楚，重要对象完整。特写可有意省略画外身体，不能误裁本镜头需要的脸、手、样品或文字。
- 不使用渐变、明暗塑形、3D、电影灯光、写实人体、复杂纹理、精致卡通或专业矢量润饰。
- 文字仅在解释确有需要时出现，短、拼写正确、易读、手写感；不把整段旁白印到图里。
